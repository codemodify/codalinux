# Wallpapers

Place default stills here. Build/install path: `/usr/share/backgrounds/codalinux/`.

`default.png` is the branded gradient used by hyprpaper and hyprlock on the live session. It must be present in git so the ISO is not a black desktop. Regenerate with `python3 scripts/gen-wallpaper.py`. `build-iso.sh` also generates it if the file is missing. A greetd background hook is still later.
