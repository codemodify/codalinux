# Wallpapers

Place default stills here. Build/install path: `/usr/share/backgrounds/codalinux/`.

`default.png` is a **bright** branded still (light steel/teal gradient, Coda wordmark) used by hyprpaper and hyprlock. It must stay light enough to read on a dark VirtualBox screenshot. Regenerate with `python3 scripts/gen-wallpaper.py`. `build-iso.sh` also generates it if the file is missing. A greetd background hook is still later.
